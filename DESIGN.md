# Batyr's Way — Путь батыра

## Утверждённое направление (11 ноября 2026)

**Жанр:** фитнес-RPG с индивидуальными уровнями сложности.
**Атмосфера:** тюркская степь, юрта, волк, горы, золотые акценты на графитовом фоне.
**Герой:** только один герой, проходящий пять ступеней тюркского воина. Выбор «Атлет» и «Аниме» удалён.

| Этап | Уровни | Персонаж |
|---|---:|---|
| Новичок | 1–10 | Очень худой, бедная простая одежда, без доспехов |
| Боец | 11–25 | Окрепший, тренировочная степная одежда |
| Воин | 26–50 | Уверенный, лёгкая броня тюркского воина |
| Батыр | 51–75 | Сильный, выразительная боевая экипировка |
| Легенда | 76–100 | Легендарная броня, волк, эпичная степная атмосфера |

На каждом этапе нужна своя **отдельная оригинальная иллюстрация того же персонажа**. Сейчас использованы временные изображения: для старших рангов один рисунок повторяется. Это задача следующей графической итерации.

## Настраиваемые упражнения

- Пользователь задаёт название, повторения или время, количество подходов, необязательный вес.
- Подходы отмечаются после выполнения. Отметка не является доказательством реального движения.
- Нагрузка в игровых баллах = сумма выполненных повторений + сумма секунд/30.
- Полноценная тренировка: **минимум 2 подхода и 12 баллов нагрузки**, либо **10 минут кардио** (ходьба, велосипед, бег, плавание и т. п.) даже в одном подходе.
- Отдельное одно отжимание в день записывается как активность, но **не является полноценной тренировкой, не даёт XP и не приближает звание «Батыр»**.
- XP начисляется за полноценную тренировку один раз в день: 24 + min(14, floor(нагрузка / 10)), максимум 38 XP.
- Для каждого следующего уровня нужны **три одновременных условия**:
  1. XP >= ceil(65*(L-1) + 0.5*(L-1)^2);
  2. полноценных тренировок >= ceil(1.5*(L-1) + 0.012*(L-1)^2);
  3. нагрузка >= max(минимум этапа, ceil(персональная база * (1 + 0.006*(L-1)))) минимум дважды за последние шесть зачтённых тренировок.
- Минимумы этапов в условных баллах нагрузки: **Новичок 12; Боец 20; Воин 30; Батыр 45; Легенда 60**. Для ходьбы 45 баллов соответствуют примерно 22,5 минуты суммарной ходьбы; для упражнений с повторениями — 45 суммарным повторениям в выбранных упражнениях.
- Персональная база фиксируется по первым трём полноценным тренировкам, минимально 12 баллов. Прогресс относительно собственной базы, не единый норматив отжиманий для всех.
- Этапы подтверждаются обычным переходом через требуемый уровень. Никакого прохождения только за накопление XP.
- Новую нагрузку следует увеличивать в рамках возможностей человека; игровой норматив не должен заменять медицинские рекомендации и не подтверждает физическую силу автоматически.

## Текущее состояние

Версия **0.7** реализует прототип логики тренировок, статистику, пять этапов, блокировку нечестного повышения ранга и полосу прохождения уровня. Имеются анимированные схематичные упражнения и встроенные изображения. **Пять отдельных финальных персонажей, полноценный 3D, автоматическое подтверждение движений, продвинутая система безопасности и стабильная релизная подпись ещё не реализованы**.
